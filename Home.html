— pipeline. SC.07 / TK.01
— DU BRIEF AU FINAL CUT

Quatre phases.
Une seule équipe.

PHASE 01

Pré-prod.

Brief, écriture, casting, repérages, planning. On cadre tout avant d'allumer la première caméra.

  • ✓ Note d'intention
  • ✓ Scénario · storyboard
  • ✓ Casting · repérages
  • ✓ Plan de tournage · devis
PHASE 02

Production.

Tournage. Une équipe, un set, un plan. Pas de plan B — juste un plan qui tient.

  • ✓ Crew internalisé
  • ✓ Matériel Arri · Sony
  • ✓ Direction artistique
  • ✓ Régie · intendance
PHASE 03

Post-prod.

Montage, grading, sound design, motion. Livré prêt à diffuser, sur tous les canaux.

  • ✓ Montage offline · online
  • ✓ Étalonnage Resolve
  • ✓ Sound design · mix
  • ✓ Motion · livrables
PHASE 04

Suivi.

Le projet ne s'arrête pas à la livraison. On ajuste, on décline, on accompagne la diffusion.

  • ✓ Déclinaisons multi-format
  • ✓ Retouches · versions
  • ✓ Livraison broadcast · web
  • ✓ Archivage masters
