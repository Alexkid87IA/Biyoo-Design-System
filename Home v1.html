— DU BRIEF AU FINAL CUT

Le pipeline.

3 PHASES · 1 ÉQUIPE
PHASE 01

Pré-prod.

Brief, écriture, casting, repérages, planning, devis. On cadre tout avant de tourner.

  • ✓ Note d'intention
  • ✓ Scénario / storyboard
  • ✓ Casting + repérages
  • ✓ Plan de tournage + devis
PHASE 02

Production.

Tournage. Une équipe, un set, un plan. Pas de plan B — juste un plan.

  • ✓ Crew internalisé
  • ✓ Matériel Arri / Sony
  • ✓ Direction artistique
  • ✓ Régie + intendance
PHASE 03

Post.

Montage, grading, sound design, motion. Livré, prêt à diffuser.

  • ✓ Montage offline / online
  • ✓ Étalonnage Resolve
  • ✓ Sound design + mix
  • ✓ Motion + livrables
